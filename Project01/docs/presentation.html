15초 경찰·군의 드론이나 로봇이 용의자에게 접근하기 전에, 영상만 보고 "진짜 항복인지, 손에 뭔가 숨겼는지"를 가려 주는 HUD를 만들었습니다.

문제와 목표

상황 — 정찰 자산(드론·로봇)이 대상을 원격 관찰. 접근 전에 "항복 의사가 있는지 / 항복하는 척 공격을 준비하는지"를 영상만으로 가린다.

출력 — 사람마다 3상태, 우선순위 DANGER > UNKNOWN > SURRENDER

상태조건
DANGER한 손이라도 가려짐(손목 안 보임 / 1초 연속 손 못 찾음) 또는 물체를 들고 있음
SURRENDER양손 모두 펴짐 + 물체 없음 + 양 손목이 어깨보다 위
UNKNOWN그 외 — 손 내림·주먹·손목 화면 밖·인식 실패

상태는 연속 5프레임 같아야 바뀜(디바운스). 잠깐 가려지면 Kalman 예측으로 최대 30프레임 위치·직전 상태 유지.

30초 색 분할·윤곽은 검출기 박스 안에서 물체 영역만 정밀하게 남기는 단계. 관계성은 '객체↔손 겹침'과 '손목↔어깨 높이' 두 군데.
Q LAB 이유? L과 a·b 분리 → 조명 변화에 색 범위 유지. CLAHE는 L에만 → 색 임계값 영향 없음. Q CLAHE 효과? 그늘진 손 안 물체의 L 대비 상승. 테스트에서 L 표준편차 증가 확인.

맥(M2) 실측, 프레임당

  • 카메라 읽기 13ms
  • Pose 24ms (사람 있을 때)
  • EfficientDet 37ms — 짝수 프레임만

Q 재사용이 판정을 틀리게? 갱신 주기(4프레임)가 디바운스(5)보다 짧아 지연 1프레임 수준. Q Jetson fps? 미측정(맥 기준). 느리면 DETECT_EVERY_FRAMES 늘리거나 pose lite 모델.

객체 추적사람마다 명찰(ID)을 유지한다

  • 몸 중심 = 어깨 중점. 엉덩이 포함 평균은 앉은 자세에서 엉덩이 visibility가 깜빡여 중심이 100px 점프 → ID 바뀜 (실측으로 교정)
  • 사람별 cv2.KalmanFilter — 등속 모델, 상태 (x, y, vx, vy), 측정 (x, y)
  • 매칭: 이전 중심 ↔ 새 측정, 가까운 쌍부터 짝짓기(greedy). 허용 거리 max(100px, 0.8 × 어깨 너비)
  • 측정 없으면 예측으로 30프레임 버팀(PREDICTING, 점선 박스) → 넘기면 삭제. ID 재사용 없음

35초 Pose는 프레임마다 사람 목록 순서가 바뀔 수 있어 "지난 프레임에 어디 있었나"로 같은 사람을 이어 붙입니다. 가까운 사람은 화면에서 크게 움직이니 허용 거리를 어깨 너비에 비례시켰습니다(실측: 어깨 160px 이상에서 몸을 돌리자 ID 1→6).
Q Kalman 필요? 잠깐 가려져도 위치·직전 상태 유지. 없으면 가려질 때마다 새 ID·UNKNOWN 리셋. Q greedy가 틀리는 경우? 두 사람 교차 시 뒤바뀔 수 있음(정석은 헝가리안). 최대 3명·시연 환경엔 충분.

손 판정어디를 얼마나 자르고, 무엇을 재나

  1. 손목 검사 순서: 화면 밖 → OUT / visibility < 0.5 → HIDDEN. 순서를 바꾸면 화면 밖 손이 전부 위험으로 뜸
  2. crop: 중심 = 손목·검지 중점, 반폭 = 어깨 너비 × 0.9 → 멀든 가깝든 손이 같은 비율로 들어옴
  3. HandLandmarker 21점 → 네 손가락 둘째 마디 각도 모두 ≥ 160° → OPEN, 아니면 CLOSED, 못 찾으면 NOT_FOUND
  4. NOT_FOUND 15프레임(≈1초) 연속 → HIDDEN. 등 뒤 손도 Pose가 "보인다"고 추정하는 실측 사례 대응

각도는 crop 크기를 곱한 픽셀 좌표로 잰다 — 가장자리에서 잘린 crop은 정사각형이 아니라 정규화 좌표로 재면 각도가 틀어진다.

물체 판별세 번 바꾼 설계 결정

① 파란색 분할

"파란 물건 = 무기 모형" — 손 crop 안 LAB inRange

✗ 파란 노트 b≈110이 임계값 경계에 걸림. 물체가 손 crop 밖으로 나가 놓침

② 손바닥 피부색 대비

손바닥 안에 피부색과 다른 색이 있으면 물체

✗ 물체를 쥐면 손 랜드마크가 주먹(피부) 위에 놓이고 물체는 손 밖. 영역을 넓히면 옷·벽이 들어와 빈 주먹과 구분 불가

③ 검출기 = "존재 감지기" (최종)

Target 상태기계: 깜빡이는 검출에서 Event Log가 납득되게 나오는가

확인하려는 질문. 카메라가 매 프레임 보는 것은 깜빡이고 떨린다. 이것을 "다른 값이 T초 동안 계속되면 인정한다"는 규칙 하나로 걸렀을 때, 확정한 규칙 (Event 4종, 출현·이탈은 한 건, 그 외는 변화 한 가지당 한 건)대로 납득되는 Event Log가 나오는가? 특히 짧게 끊기는 검출, 한순간에 여러 가지가 바뀌는 경우, near/far 경계나 물체 검출이 떨리는 경우를 본다.

Target은 상태기계가 "있다"고 인정한 사람이다. 화면에 보인다고 바로 Target이 되지 않는다. Project03 제출물이 아니며, 여기서 확인한 규칙만 Python으로 다시 쓴다.

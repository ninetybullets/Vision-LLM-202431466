역할 분리 — 판정은 규칙, 설명은 LLM

층하는 일성질
규칙 상태기계(state_machine.py)Target State(Zone, Held Object) 판정, 바뀐 것만 Event로결정론: 같은 입력 → 같은 Event 열
LLM(Gemma 4 E2B, reporter.py)Event Log 텍스트로 SITREP·질의응답이미지 입력 없음, 위험 판정 없음(ADR 0001)

왜 나눴나

  • 환각: SITREP 옆 근거 Event 원문(Evidence) 동시 출력 → 문장 한 줄씩 대조 가능
  • 재현성: LLM이 위험 여부 결정 시 같은 장면에 다른 답 → 검증 불가
  • 비용: Jetson 8GB 한 대에서 YOLO와 동시 실행 → 매 프레임 LLM 호출·이미지 입력 불가

system 규칙(COMMON_RULES): 로그 사실만(없으면 '관측되지 않음') / 한국어 낱말만 / 위험 여부 판정 금지 / 2~3문장

파이프라인 — 파일 11개, 두 줄의 흐름

  • 메인 스레드(프레임마다): camera → detector(YOLO11n + 추적 id) → state_machine(build_observations → step) → event_log + hud, 조립은 main.process_frame
  • event_log: 메모리 목록 + logs/events-YYYYMMDD-HHMMSS.jsonl / hud: 박스·Target id·Zone·Held Object·FPS·Motion Level, 영어만
  • 작업 스레드(Event·질문 때만): reporter(Gemma 4 E2B, SITREP + Evidence 터미널 출력) → voice(Whisper STT / Piper TTS)
  • 그 밖: motion(Motion Level), platform_config(트랙별 경로·명령), bench(측정표)
  • 한 코드 두 트랙: 개발·테스트는 Mac 사본, 제출본은 Jetson 전용 카메라 파이프라인(camera.JETSON_PIPELINE, 읽기 제한 시간 JETSON_READ_TIMEOUT_MILLISECONDS 3초)

Event 4종

Event조건임시값
appeared보이는 상태 T 동안 지속 → 확정 프레임의 Zone·물체 담음DEBOUNCE_SECONDS = 1.0
goneTarget이 T 동안 안 보임 → 마지막 Target State 담고 삭제같은 T
zone_changed사람 박스 높이 / 프레임 높이 ≥ 기준 → near, 아니면 far. 새 값 T 유지NEAR_HEIGHT_RATIO = 0.5
object_changed물체 박스 중심이 사람 박스 안 → 보유. 물체 종류별로 따로 디바운스HELD_OBJECT_CLASS_NAMES 4종(knife·bottle·cell phone·backpack)
  • Event 필드 5개 고정: timestamp, target_id, kind, before, after

LLM 트리거 3경로

LLM 호출 경로 셋뿐 (매 프레임·주기 호출 없음)

  1. Event 발생 → SITREP(Event Batch + Snapshot)
  2. 키 1(지난 1분 변화)·2(현재 상황) → Preset Question
  3. 키 v → 5초 녹음 → Whisper → Spoken Question. 음량 RMS < 500(SILENCE_RMS_THRESHOLD) → Gemma 호출 없이 "질문을 듣지 못했습니다."
  • 질문 근거: 최근 60초(QUESTION_WINDOW_SECONDS) Event + Snapshot
  • 우선순위: 질문 > 대기 중 Event Batch. 생성은 한 번에 하나, 생성 중 쌓인 Event는 다음 SITREP 한 번에
